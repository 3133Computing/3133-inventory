# 3133 Inventory MVP Implementation Plan

> **For Hermes:** Use subagent-driven-development skill to implement this plan task-by-task.

**Goal:** Turn the Snipe-IT fork into a simpler 3133 Inventory MVP focused on sellable/consumable stock, checkoutable loaners, barcode scanning, and QR-label-ready workflows.

**Architecture:** Keep Snipe-IT's stable Laravel/Auth/permissions/audit foundations, but add a thin 3133-specific inventory layer instead of deleting core modules immediately. Use `Consumable` records for sellable stock keyed by `item_no` barcodes, `Asset` records for loaners keyed by `asset_tag`, and `action_logs` as the stock movement ledger.

**Tech Stack:** Laravel 12, PHP 8.2, Blade/AdminLTE 2, PHPUnit feature tests, existing Snipe-IT models and policies.

---

## MVP Scope

### Keep and surface
- Inventory scan page
- Sellable Stock (`Consumable`)
- Loaners / Assets (`Asset`)
- Customers (`User`/Company model for now)
- Existing QR/label support for Assets

### Hide from primary workflow for now
- Licenses
- Accessories
- Components
- Kits
- Heavy reports/import UX unless needed

Do not delete these backend modules in the first phase. Hide them from navigation/dashboard first so the product becomes focused without destabilizing migrations, policies, or API controllers.

## Task 1: Add inventory scan + stock movement backend

**Objective:** Add a dedicated `Inventory` namespace with barcode lookup and consumable receive/remove actions.

**Files:**
- Create: `app/Http/Controllers/Inventory/ScanController.php`
- Create: `app/Http/Controllers/Inventory/ConsumableStockController.php`
- Modify: `routes/web.php`
- Create: `resources/views/inventory/scan.blade.php`
- Create: `tests/Feature/Inventory/InventoryScanTest.php`
- Create: `tests/Feature/Inventory/ConsumableStockMovementTest.php`

**Behavior:**
- `GET /inventory/scan` renders a focused scanner page.
- `POST /inventory/scan/lookup` accepts `barcode` and returns JSON:
  - consumable matched by `consumables.item_no`
  - asset matched by `assets.asset_tag`
  - 404 JSON for unknown barcode
- `POST /inventory/consumables/{consumable}/receive` increments `qty` and logs `stock received`.
- `POST /inventory/consumables/{consumable}/remove` decrements `qty` and logs `stock removed`.
- Removal cannot make stock negative.

**Verification:**
```bash
php artisan test tests/Feature/Inventory/InventoryScanTest.php tests/Feature/Inventory/ConsumableStockMovementTest.php
```
